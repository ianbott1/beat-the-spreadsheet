Every game

Every matchup of the season. Open one to see both lineups as they were locked, with ESPN’s projection and the actual points for every player, and every forecaster’s card for that game.

A dead start is a starter who wasn’t going to play: a zero projection when the lineup locked. A deviation is a starter the manager chose over ESPN’s projections, which the models never see. Best marks the players in the best lineup the roster could have set in hindsight. Notes count both lineups in a game.
